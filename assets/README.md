# 자산

| 폴더 | 내용 |
|---|---|
| `images/` | 현재 게임에 포함된 이미지 원본 |
| `audio/` | 현재 게임에 포함된 음성·효과음 원본 |
| `models/` | 노인·NPC·침대의 기하 데이터 |
| `data/` | 그림 좌표, 음성·그림 매핑 등 JSON |
| `vendor/` | 현재 사용 중인 Three.js 0.180.0과 라이선스 |
| `video/` | 두 실행본이 함께 읽는 10초 시작 영상. HTML에 내장하지 않는 상대 파일 |

`manifest.json`에 이진 파일의 MIME·크기·SHA-256·사용 위치(`usedBy`)가 있습니다. 중복 자산은 같은 파일을 공유합니다. 짧은 해시는 중복 방지용이며 사용 화면은 `usedBy`와 스테이지의 `art.js`·`audio.js`·`npc-assets.js`에서 확인합니다.

빌드가 기존 게임 이미지·음성·모델 파일을 읽어 data URI와 모델 값으로 내장합니다. `video/`의 시작 영상은 예외로 HTML 옆의 상대 경로를 그대로 읽습니다. USB로 전달할 때도 이 폴더를 함께 복사합니다. FBX·OBJ로 변환하지 않고 현재 브라우저에서 사용하던 JSON 형식을 보존했습니다. 모델 수치와 라이브러리가 게임 동작 코드를 가리지 않도록 분리했습니다.

기존 코드의 모델·음원 출처 주석과 Three.js 라이선스는 유지했습니다. 이 추출은 새 자산 제작이나 독립적인 재배포 라이선스 부여를 뜻하지 않습니다.

자산을 의도적으로 교체하면 해당 MIME·해시·크기와 `usedBy`도 함께 관리합니다. `npm test`는 누락과 manifest 불일치를 검사합니다.

## 시작 영상 출처

`video/elder-transformation-10s.mp4`는 실제 PNG 아틀라스를 기존 UV의 `MeshLambertMaterial.map`에 입힌 r03 편집 영상입니다. 옷을 다시 칠하는 셰이더는 이 렌더에서 사용하지 않습니다. 얼굴·손·노출 피부를 보존하고 목선 피부를 복원한 PNG를 사용하며, 칼라·리본·주름치마는 기존 별도 3D 형태를 유지합니다. 추가 음악·음성이나 참조 영상의 원본 프레임은 포함하지 않습니다. PNG·원본 모델을 이번 배포에 추가하지 않고 편집 영상만 교체합니다.

영상 URL의 `v` 값은 MP4 SHA256 앞 12자리로 맞춰 이전 r02 영상 캐시와 구분합니다. 최초 r02 게시와 검증 기록은 이전 커밋에 보존됩니다.

기초 인체 메시의 출처는 Lucas Pope / 3909의 *Return of the Obra Dinn* GDC 2016 무료 데모 v0.1.23입니다. [공식 데모 페이지](https://dukope.itch.io/return-of-the-obra-dinn)의 공개 사실과 별도 메시 재사용 허락은 구분합니다. 확인한 공식 안내와 데모 Readme에는 별도 재사용 라이선스를 찾지 못했으며, 이 기록이 권리 확보나 법적 판단을 뜻하지 않습니다. 이번 추가 파일은 편집된 10초 영상이며 데모 ZIP·게임 덤프·추출 원본 메시를 새로 추가하지 않습니다.
