# 기억 스테이지 엄마와 아이 모델

## 엄마(mom-model.json, 2026-11-23 Claude Code)

아빠 모델(dad-model.json)을 바탕으로 여자 몸으로 고쳤습니다: 어깨·허리를 좁히고 엉덩이를 넓히고 가슴을 조금 내고 팔을 가늘게, 벌어진 발을 모았습니다. 무릎 아래 치마(원통 메시)와 뒤통수의 쪽진 머리(타원 메시)를 몸(body)에 붙였고, 칫솔(brush)은 예전 엄마 모델의 칫솔을 새 오른손 자리로 옮겼습니다. 키는 1.6m입니다. 팔(armL·armR)에는 어깨에서 손 쪽으로 늘어진 방향 `down`이 있어 팔을 뻗을 때 -Y 대신 씁니다.

2026-11-24 Claude Code: 몸만 더 여자 몸으로 고쳤습니다(얼굴·머리·스킨은 그대로). 어깨 좁게, 허리 더 잘록하게, 가슴 조금 더, 팔 가늘게(0.8배)·짧게(0.93배)·어깨에서 5도 벌림(넓어진 치마에 손이 묻히지 않게), 치마는 허리 쪽은 좁고 엉덩이 쪽(높이 0.74m)에서 넓게. 칫솔은 오른손을 따라 옮겼습니다. 고치기 전 판: 웹디2\materials\backup\20261124-0123-mom-body-before.

아빠 모델의 몸 메시는 Lucas Pope / 3909의 *Return of the Obra Dinn* GDC 2016 무료 데모에서 나왔습니다(`assets/README.md` 참고, 별도 재사용 허락은 찾지 못함).

스킨 `mom-model-atlas.webp`는 1254×1672 회색조입니다. 위 1254×1254는 아빠 모델과 같은 UV 배치이고, 아래 418px는 치마+앞치마(아래에서 42~418px)와 칫솔 칸(왼쪽 아래 40×40)입니다. 그림은 Codex 이미지 생성(아빠 스킨을 바탕으로 편집)으로 그렸습니다. UV v=0은 아래입니다.

## 아이(child-model.json)

형상은 three.js 기본 도형을 조합해 직접 생성했습니다. 외부 모델은 사용하지 않았습니다.

좌표는 미터 단위, 발바닥 y=0, 정면 +Z입니다. 각 부품 positions는 모델 공통 좌표이며 pivot은 같은 좌표계입니다. 아틀라스는 512×512 회색조 8개 색상 영역으로 구성되며 UV v=0은 아래입니다. 원본 생성 스크립트는 작업 폴더 make-models.cjs입니다.
