# 기억 스테이지 엄마와 아이 모델

형상은 three.js 기본 도형을 조합해 이 작업에서 직접 생성했습니다. 외부 모델은 사용하지 않았습니다. 엄마의 묶은 머리와 앞치마는 기존 mom-stand.png를 참고했습니다.

좌표는 미터 단위, 발바닥 y=0, 정면 +Z입니다. 각 부품 positions는 모델 공통 좌표이며 pivot은 같은 좌표계입니다. 팔을 회전할 때 정점에서 pivot을 빼거나 그룹을 pivot에 두고 위치를 보정하세요. armR은 인물 자신의 오른쪽(-X)입니다. brush는 오른손 위치를 중심으로 독립 부품이며, 오른팔 움직임에 함께 연결해야 합니다.

아틀라스는 512×512 회색조 8개 색상 영역으로 구성되며 UV v=0은 아래입니다. 부품들은 색상 영역 중앙을 참조합니다. 원본 생성 스크립트는 작업 폴더 make-models.cjs입니다.
