공통 영상 코드·스타일과 두 시작 템플릿만 게임 시작 흐름에 추가했습니다. 17개 내장 게임 문서는 초기 소스 분리 기준 SHA와 모두 동일합니다. 미로 이동·감도·Pointer Lock·골목·NPC·각 게임 규칙·저장 소스는 수정하지 않았습니다. 실제 전용 AI 끄기 방해는 개발자용에 넣지 않았습니다. 첫 클리어 뒤 글리치·새 사운드·3페이즈 스토리는 추가하지 않았습니다.

영상은 HTML에 base64로 넣지 않습니다. 오프라인·USB 실행은 HTML 옆에 `assets/video/`를 같은 상대 위치로 함께 둡니다. 영상 종료·Escape 건너뛰기·미디어 오류 후 기존 화면과 입력이 복구됩니다. 자동 재생이 막히면 영상 클릭 또는 Enter/Space로 재생합니다.
