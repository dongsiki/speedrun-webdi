# 엔딩 크레딧 + 할아버지 춤 이스터에그

2026-10-29 사용자 지시(「걍춤: 엔딩 크레딧에 할당」, 「걍춤은 이스터에그로서 작용하는 거. 발견한 게 이 할아버지 춤인거.」).

- 크레딧이 땅파기 로비와 같은 흰 바닥 위로 아래에서 위로 올라간다(42초).
- 바닥은 크레딧 도중에도 팔 수 있다. 할아버지가 묻힌 자리(화면 가운데, 표시 없음)를 계속 파면 구멍 사이로 할아버지가 보이고, 그 자리의 38%가 드러나면 땅과 크레딧이 걷히며 기존 「그냥 춤」이 음악과 함께 재생된다. 묻힌 자리 근처를 팔 때만 흙 소리가 조금 둔해지고 흙 부스러기가 조금 더 튄다.
- 크레딧 글: 제목 「스피드런」과 기존 출처 표기(Music なまーく / Only Dance!, Character mesh Lucas Pope / 3909 · Obra Dinn GDC 2016 demo, Three.js MIT)만.
- 춤 화면은 `src/extras/elder-dance/`의 파일을 `@inline`으로 그대로 쓴다(원본 수정 없음, 같은 요소 id).

## 진입점

| 파일 | 쓰임 |
|---|---|
| `launch.js` | 본편에 `@inline` 하면 `EndingCredits.play()`가 생긴다. 전체 화면 iframe으로 크레딧을 띄우고, 끝나면 닫은 뒤 `Promise<{found}>`를 푼다. |
| `index.template.html` | 크레딧 화면 자체(단독 문서). `document.json`이 이것을 가리킨다(`@standalone`). |
| `credits.js` | 땅·크레딧·발견 동작. 끝나면 부모에 `{channel:'speedrun-ending-credits-v1', type:'done', found}`를 보낸다. |

끝나는 때: 크레딧이 다 올라간 뒤(묻힌 자리를 파는 중이면 손을 멈추고 3.2초 뒤), 또는 춤 화면 왼쪽 위 화살표.

예정 위치: 3페이즈 진엔딩 뒤(Codex와 합의). 아직 어디에도 연결하지 않았다(01·02, phase3.js, documents.json 수정 없음). 묶은 크기 약 14.6MB(three.js·모델·음원 포함, 개발자용 「05 그냥 춤」과 같은 자산).
